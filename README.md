# CliCar CRM + ERP — Planos

Landing page de apresentação e comparação dos quatro planos do CliCar CRM + ERP.

Este repositório contém a versão compilada em um único arquivo (`index.html`), publicada pelo GitHub Pages.
O código-fonte (React + Vite) fica no projeto `megap-planos`; para atualizar o site, rode `npm run build:single`
e substitua o `index.html` daqui pelo arquivo gerado em `dist-single/index.html`.
