# CliCar app — Tudo a um clique.

Landing page do CliCar app (ERP automotivo): diferenciais, recursos e comparação dos quatro planos.

Este repositório contém a versão compilada em um único arquivo (`index.html`), publicada pelo GitHub Pages,
mais o ícone (`favicon.svg`, `apple-touch-icon.png`) e a imagem de compartilhamento (`og-image.png`).
O código-fonte (React + Vite) fica no projeto `megap-planos`: rode `npm run build:single` e substitua o
`index.html` daqui pelo arquivo gerado em `dist-single/index.html`.
